🚀 Smart Service Assist
📌 Descrição do Projeto
O Smart Service Assist é uma aplicação web desenvolvida para modernizar o atendimento digital de pequenas empresas utilizando tecnologias Web, automação e Inteligência Artificial.
O projeto foi desenvolvido para a disciplina Padrões Web para No Code e Low Code, demonstrando a aplicação prática de HTML, CSS e JavaScript na construção de uma solução digital moderna e responsiva.
________________________________________
🎯 Problema
Muitas pequenas empresas utilizam apenas redes sociais para divulgar seus serviços e realizar atendimentos.
Esse modelo gera diversos desafios:
•	Atendimento manual;
•	Demora nas respostas;
•	Falta de automação;
•	Dificuldade em captar novos clientes;
•	Organização limitada das solicitações.
________________________________________
💡 Solução Desenvolvida
Foi desenvolvida a plataforma Smart Service Assist, uma aplicação web capaz de apresentar os serviços da empresa, recomendar soluções ao cliente, receber solicitações de orçamento e disponibilizar atendimento inteligente utilizando Inteligência Artificial.
________________________________________
🌐 Funcionalidades
Página Inicial
Apresentação da empresa e dos serviços oferecidos.
Catálogo de Serviços
A plataforma apresenta:
•	Criação de Sites
•	Automação Empresarial
•	Chatbots com Inteligência Artificial
Recomendação Automática
O usuário seleciona sua necessidade e o sistema recomenda automaticamente o serviço mais adequado.
Assistente IA Gemini
Foi implementada uma interface de chatbot preparada para integração com a API Gemini do Google AI Studio.
O chatbot pode ser utilizado para:
•	Tirar dúvidas;
•	Apresentar serviços;
•	Simular atendimento automatizado;
•	Recomendar soluções ao cliente.
Formulário de Orçamento
Permite o envio de solicitações de contato e orçamento de forma simples e intuitiva.
________________________________________
🤖 Recurso de Inteligência Artificial
O projeto utiliza integração com o Google Gemini através da API disponibilizada pelo Google AI Studio.
A solução foi preparada para:
•	Processar perguntas em linguagem natural;
•	Fornecer respostas inteligentes;
•	Orientar clientes;
•	Simular atendimento automático.
A integração foi desenvolvida utilizando JavaScript e consumo de APIs REST.
________________________________________
🔐 Observação sobre a Integração com IA
Por motivos de segurança, a chave de acesso da API Gemini não foi publicada no repositório GitHub público.
A divulgação de chaves em repositórios públicos pode permitir o uso indevido por terceiros.
Durante o desenvolvimento do projeto, a integração com o Gemini foi implementada e testada utilizando o Google AI Studio.
Na versão pública hospedada no GitHub Pages a chave foi removida seguindo boas práticas de segurança.
Toda a estrutura de integração permanece implementada, demonstrando a utilização de Inteligência Artificial Generativa na solução.
