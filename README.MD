Smart Service Assist
📌 Sobre o Projeto
O Smart Service Assist é uma solução web desenvolvida para modernizar o atendimento digital de pequenas empresas por meio de tecnologias Web, conceitos No-Code/Low-Code e Inteligência Artificial.

O projeto foi desenvolvido como parte da disciplina de Padrões Web para No Code e Low Code, demonstrando a aplicação prática de HTML, CSS e JavaScript na personalização de uma solução digital moderna.

🎯 Problema
Muitas pequenas empresas utilizam apenas redes sociais para divulgar seus serviços.

Esse modelo apresenta algumas limitações:

Atendimento manual;
Demora nas respostas;
Dificuldade para captar clientes;
Falta de organização das solicitações;
Ausência de automações.
💡 Solução Desenvolvida
Foi criada uma aplicação web responsiva chamada Smart Service Assist.

A plataforma oferece:

Apresentação dos serviços;
Solicitação de orçamento online;
Recomendação automática de serviços;
Estrutura para integração com Inteligência Artificial;
Interface moderna e responsiva.
🚀 Funcionalidades
Página Inicial
Apresentação da empresa;
Banner principal;
Navegação simples.
Catálogo de Serviços
Criação de Sites;
Automação Empresarial;
Chatbots com IA.
Sistema de Recomendação
O usuário pode selecionar uma necessidade e receber uma recomendação automática de serviço através de JavaScript.

Formulário de Contato
Permite que o usuário envie solicitações de orçamento.

Responsividade
A aplicação adapta o layout para:

Smartphones;
Tablets;
Computadores.
