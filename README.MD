Smart Service Assist
📌 Descrição do Projeto
O Smart Service Assist é uma aplicação web desenvolvida para modernizar o atendimento digital de pequenas empresas por meio da utilização de tecnologias Web, automação e Inteligência Artificial.
O projeto foi desenvolvido para a disciplina de Padrões Web para No Code e Low Code, demonstrando a aplicação prática dos conceitos de HTML, CSS, JavaScript e integração com IA utilizando o Google Gemini.
🎯 Problema
Muitas pequenas empresas utilizam apenas redes sociais para divulgar seus serviços e atender clientes.
Essa abordagem apresenta algumas limitações:
•	Atendimento manual;
•	Demora nas respostas;
•	Dificuldade na gestão de solicitações;
•	Falta de automação;
•	Baixa disponibilidade de atendimento.
💡 Solução Desenvolvida
Para resolver esse problema foi criada a plataforma Smart Service Assist.
A solução disponibiliza:
•	Site institucional moderno;
•	Catálogo de serviços;
•	Formulário de solicitação de orçamento;
•	Recomendação automática de serviços;
•	Atendimento inteligente com IA Gemini;
•	Interface responsiva para dispositivos móveis.
🚀 Funcionalidades
Página Inicial
Apresentação da empresa e dos serviços oferecidos.
Catálogo de Serviços
•	Criação de Sites
•	Automação Empresarial
•	Chatbots com IA
Recomendação Inteligente
O usuário informa sua necessidade e o sistema recomenda automaticamente o serviço mais adequado.
Assistente IA Gemini
Chatbot integrado à API do Google Gemini capaz de:
•	Responder perguntas;
•	Orientar clientes;
•	Informar sobre serviços;
•	Simular atendimento inteligente.
Formulário de Contato
Permite ao cliente solicitar orçamentos diretamente pela plataforma.
🤖 Recurso de Inteligência Artificial
O projeto utiliza o Google Gemini através de integração com API.
A IA é responsável por:
•	Compreender perguntas em linguagem natural;
•	Responder dúvidas dos clientes;
•	Fornecer informações sobre os serviços;
•	Simular atendimento automatizado.
A integração foi realizada utilizando JavaScript e a API Gemini disponibilizada pelo Google AI Studio.
